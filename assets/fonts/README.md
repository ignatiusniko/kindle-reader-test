# Fonts

`--features kindle` embeds `assets/fonts/ReaderFont.ttf` (the Kindle backend
has no system fonts). Font binaries are **not committed**.

Run `scripts/fetch-font.sh` to install DejaVu Sans (freely redistributable;
licence copied to `LICENSE-DejaVu.txt`). Any other TTF/OTF works if its
licence allows redistribution. Never copy Amazon's Kindle system fonts.
